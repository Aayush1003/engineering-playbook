|---------|--------|

| **II — Databases** | SQL & NoSQL, Replication, Indexes, Normalization, ACID/BASE, CAP Theorem, Transactions, Sharding, Consistent Hashing, Federation |

| **V — Case Studies** | URL Shortener, WhatsApp, Twitter, Netflix, Uber |
