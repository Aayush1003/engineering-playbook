# 🔧 DevOps

> DevOps is the combination of **people**, **processes**, and **products** to continuously deliver value to end users.

---

## 🗺️ Roadmap

| # | Topic | Key Concepts |
|---|-------|-------------|
| 1 | **Git & Branching** | `clone`, `add/commit/push/pull`, `merge`, `rebase`, resolving conflicts, feature branch & trunk-based workflows |
| 2 | **CI/CD & Jenkins** | Pipeline stages, `Jenkinsfile`, build triggers, artifacts |
| 3 | **Containers (Docker)** | Images vs containers, `Dockerfile`, `docker run`, `docker-compose`, networking |
| 4 | **Kubernetes** | Pods, Deployments, Services, ConfigMaps, readiness/liveness probes, `kubectl` |
| 5 | **IaC & Automation** | Terraform (`providers`, `plan/apply`), Ansible playbooks, idempotency |
| 6 | **Linux & Shell Scripting** | File operations, piping, `grep/awk/sed`, permissions, `systemctl`, process management |
| 7 | **Build Tools & Packaging** | Maven/Gradle basics, artifact repos (Nexus/Artifactory) |
| 8 | **Monitoring & Logging** | Prometheus, Grafana, ELK stack (Elasticsearch, Logstash, Kibana) |
| 9 | **Cloud Basics (AWS/Azure/GCP)** | EC2/VMs, S3/Storage, IAM, CLI usage |
| 10 | **Networking** | Ports, HTTP vs HTTPS, DNS, load balancers, container networking |
